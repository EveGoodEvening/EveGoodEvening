# Lessons

- This repository is the GitHub profile README. Keep projects under topical headings in HTML tables (two-column for cover cards; "Agent configs & plugins" is single-column, one text card per row, at the owner's request; the heading was "AI coding agents" until the owner renamed it, since the section holds configs, a skill and plugins rather than agents), with the repository link in the project name and any live site linked from the card (cover image and a "Play online" / "Browse" link).
- Layout: a one-line intro, then sections. No illustrated hero banner: the owner found the animated dusk/night skyline with a neon 晚上好 sign and an italic "Good evening" headline cringe, and it was removed. Keep the top plain; don't add decorative or pun-on-the-name artwork without asking. Projects with something to look at get a 960×540 cover in `assets/covers/`; the rest are text cells. GitHub stripes every second `<tr>`, so give each row of a multi-row grid (text or cover cards) its own `<tbody>`; pad an odd last card with an empty `<td width="50%">`.
- Right-column cover cards end their "Play online" / "Read chapter 1" links with `<br><br>` to leave one empty line above the bottom border, at the owner's request. GitHub's Markdown API preserves these trailing breaks.
- For the hand-walker cover, the owner explicitly requested direct image generation through Codex CLI, not another programmatically drawn SVG. The cover is now `assets/covers/hand-walker.jpg`; the obsolete SVG and its generator were removed. Codex's native `image_gen` tool saves actual raster outputs under `~/.codex/generated_images/<thread>/`. Verify that the returned file exists and opens before claiming generation succeeded; only resize or convert the generated artwork, rather than redrawing it in code.
- GitHub sanitizes README HTML (no `style`, no CSS classes). Check the output with `POST https://api.github.com/markdown` (works unauthenticated) and preview it with `github-markdown-css` in light and dark before pushing; screenshots go through `heavy-gate`.
- Game screenshots: camhead-man-modern, hand-walker-parkour and honey-i-want-fish have `docs/screenshots/` (hand-walker-parkour's cover is `corridor.png` downscaled from 1280×720; its default branch is `feat/parkour-game`; honey-i-want-fish's cover is `megalodon.jpg` downscaled from 1600×900); camhead-man's screenshots only exist in its git history (commit `8a6febc`, reverted from that repo's README).
- To resolve renamed GitHub projects, follow the old repository's GitHub API redirect and use the returned `html_url` and `homepage` for the profile links; verify the new GitHub Pages URL independently.
- DeepSeek Harness (DSH) plugins (`dsh-autoresearch`, `dsh-llmwiki`) are the last two rows of "Agent configs & plugins" (grouped by audience, not packaging; `skill-optimizer` is the precedent for installable agent add-ons), each described as an "unofficial" DeepSeek Harness plugin (they are not from deepseek-ai) and linking its npm package; `dsh plugin` needs `--profile <name>`, so the cards show no bare install command. Their default branch is `master`, not `main`. The llmwiki package is scoped, `@evegoodevening/dsh-llmwiki`; the unscoped `dsh-llmwiki` on npm belongs to another project. `dsh-autoresearch` is unscoped.
- hand-walker-parkour (《手行者 · 跑酷》) is the game adaptation of the novel hand-walker: its card in "Games" links the novel, and the novel's card in "Explainers & writing" links back.
- Preview screenshots: `npm i playwright-core github-markdown-css` in the scratchpad (write a `{"private":true}` `package.json` there first; otherwise npm resolves a stale ancestor `package.json` under `/tmp/claude-0` and fails with ENOENT) and launch with `executablePath` set to `~/.cache/ms-playwright/chromium_headless_shell-*/chrome-*/chrome-headless-shell`, run through `heavy-gate -n 1`. Keep `playwright` out of inline `python3 -c` checks; the heavy-gate hook blocks them.
- Raster covers should be resized to 960×540 and saved as actual JPEG data (Pillow: RGB, LANCZOS, quality=85, optimize=True); a `.jpg` extension alone does not guarantee JPEG encoding. The hand-walker-parkour replacement was PNG data despite its `.jpg` name, causing unnecessary download size.
